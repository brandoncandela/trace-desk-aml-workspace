WHAT THIS TOOL IS FOR

Turn crypto transfers into a case someone else can review

Finding a crypto transaction is only the first step. An analyst also needs to explain what happened, keep the evidence, identify unanswered questions, and let another person check the work.

This workspace brings those steps together. Review an Ethereum address’s USDT transfers, explore the addresses it dealt with, save your notes and evidence, and submit a copy of your assessment for quality control (QC).

When would I use this?
  • Use it for an initial look at activity before deciding what needs deeper investigation.
  • Use it to save and reopen a case with its evidence and reasoning.
  • Use it when a reviewer needs to check an assessment and request corrections.

Start with the saved example or collect activity within a limited time window. This work sample does not identify wallet owners or automatically decide whether activity is suspicious. Reviewer identities are not verified.

4. Quality control review

Submit a copy of the evidence and assessment for QC. A reviewer can record findings, return the case for correction, or document a completed review. Save the portable case file to share the full history.

This is a file-based workflow prototype. Names are self-reported; reviewer identity, separation of duties and a tamperproof audit trail are not enforced. QC completion is not a determination that activity is lawful.

Review the submitted snapshot

Review history is included in the portable case file and case summary. Later edits require a new submission. Use the snapshot below each submission to inspect exactly what was reviewed.

Provenance & limits

New queries retain raw node requests and responses in the evidence export. The saved example’s raw evidence is in GitHub under data/raw. Block hashes are checked against node responses; saved-case checksums are verified at build time. Neither check is cryptographic proof of inclusion. Provider completeness is assumed. An event sender is not necessarily the transaction signer. Opening balances, KYC and exchange fiat-conversion records are not available here.
